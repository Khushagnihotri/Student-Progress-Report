Student Performance Prediction Using AI for Early Academic Intervention
📌 Overview

This project is a Machine Learning-based web application that predicts student academic performance using factors such as attendance, study hours, assignment scores, and LMS engagement. The system helps identify at-risk students early, enabling timely academic intervention and better decision-making.

🚀 Features
Student Performance Prediction
Risk Level Classification (Low, Medium, High)
Interactive Dashboard
Prediction History Storage
User Authentication
Responsive and Modern UI
